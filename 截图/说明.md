# 截图说明

本目录只保留了三张**不含个人信息**的界面截图，用来展示「浏览器桥」接入网页 AI 时的关键环节。

| 文件 | 内容 | 说明 |
| --- | --- | --- |
| `sidebar-full.png` | 网页 AI 首页 | 桥驱动浏览器打开网页 AI 后的初始界面，可见侧栏与输入框布局 |
| `qwen-after-login.png` | 登录方式选择页 | 展示网页 AI 支持的登录方式（邮箱验证码 / Google / GitHub / Apple） |
| `qwen-login-form.png` | 邮箱验证码登录表单 | 展示「输入邮箱 → 接收验证码」的登录流程 |

## 为什么只有这三张

原始过程截图共 35 张，大部分是全屏桌面截图或聊天窗口截图，会露出个人文件夹、聊天对象、账号头像等信息，不适合公开。本目录只保留纯界面、无个人信息的截图。

## 与架构的对应关系

这三张截图对应 README 第三节「模型层：浏览器桥」——桥需要先在本机浏览器里完成网页 AI 的登录，之后才能通过 `POST /v1/chat/completions` 把网页端当作模型使用。
